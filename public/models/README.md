# GLB model roster

The full ZIP includes five owner-uploaded rigged GLBs:

- cat-girl.glb
- cute-anime-girl.glb
- nieko.glb
- mei-tachibana.glb
- anime-girl-base.glb

See the root `ASSET_CREDITS.md` for the original authors, links and CC BY 4.0 attribution.

Models include skeletons but **no embedded animation clips**. The game poses their bones procedurally. If deploying from a GitHub source checkout that excludes the GLBs, copy them here from the full ZIP.
